# PR #17｜自動化市值篩選（研究用途）

手動工作流程 `FCN automated market-cap screening (manual research)`，**預設 pilot**：僅執行前兩個批次、共 40 檔候選股票；選擇 `full` 才會處理完整 5,237 檔候選股票（當次股票池可能變動）。

- 凍結快照與完整 20 檔批次規劃，將批次分配到最多 12 個工作節點（最多同時 3 個），每檔最多嘗試兩次。
- 只保存符合 >US$100B、低於／等於門檻、失敗三種狀態，不保存市值數值；所有結果標示 research_only。
- 彙總嚴格稽核完整性、混用快照、重複、缺漏、失敗數；有任何失敗不得宣稱完整。
- pilot 模式特意只處理 40 檔：coverage-summary 中 `remaining` 大於零、`complete_universe_screen=false` 為預期結果。
- 研究來源 yfinance 非官方；大量查詢可能被限速或封鎖。失敗需在後續 PR 設計可續跑、補查機制。
- 此工作流程**不修改第 07/08 頁**，不寫入網站，也不授權對客戶發布市場資料。候選普通股分類仍未獲權威驗證。

注意：全量模式可能產生 12 個工作節點、262 個批次與大量查詢；需明確選擇 `full` 才啟動。
